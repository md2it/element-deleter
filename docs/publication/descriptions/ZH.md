ELEMENT DELETER

悬停、点击，元素就会消失。删错了？可以恢复。

日常浏览：
移除不需要的页面元素，包括广告、弹窗和 Cookie 横幅。

面向开发、测试和设计人员：
在没有干扰块的情况下检查页面，制作干净截图，查看布局效果，或移除遮挡内容的元素。

主要功能
- 只需几次点击即可删除页面元素
- 恢复已删除的元素
- 在删除模式开启时可多次撤销删除
- 通过右键菜单删除元素
- 支持 iframe 和嵌入内容
- 删除后显示清晰通知
- 轻量、简单

隐私
- 不收集数据
- 不跟踪用户
- 不发送网络请求
- 仅使用本地设置
- 更改仅在当前页面本地生效
- 重新加载页面会恢复原始内容

界面语言
英语、法语、德语、西班牙语、俄语、阿拉伯语、简体中文。
