# RECOMMEND

---

## Entry points

- Open `Recommend` from the last item in the panel menu or the last `❤️ Recommend` item in the action context menu.

## Store actions

- Open the corresponding extension listing directly in Chrome Web Store or Firefox Add-ons.
- Copy the corresponding store link and report the result.
- Share the corresponding store link through the native system action; copy it when native sharing is unavailable.
- Keep this permanent action independent from support-survey display rules.

## Scope

- Do not promote other extensions on this page.
- Link directly to extension stores rather than through the product website.
