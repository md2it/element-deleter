# Keyboard shortcuts

> [!NOTE]
> These hotkeys exist as a hidden capability. We hid them from the product UI because without `"<all_urls>"` they do not start on cold pages; we chose mass-market users over advanced users. They are always enabled (no Settings toggles; storage cannot turn them off).

## Prefix-mode keyboard shortcut

- On/off:
   - Default `Ctrl+Shift+X` → `D`
   - Mac `Cmd+Shift+X` → `D`

## Simple keyboard shortcut

- `Esc` — turn off deletion mode
- `Ctrl+Z` / `⌘+Z` — restore
